# 📘 Lesson 10 – Add Images to Your Website

Brief introduction: In this lesson, you’ll learn how to insert and manage images in an HTML page.

## 🎓 What You Will Learn

- How to use the `<img>` tag to insert images in HTML  
- The difference between the `src` and `alt` attributes and how to use them correctly  
- How to improve accessibility and user experience with images  

## 🖼️ Overview

Images are a key element to enrich a web page. In HTML, we can use the `<img>` tag to embed images and customize their display using various attributes such as `src` (the image path) and `alt` (the image description). Images enhance usability and enrich the visual experience of a site.  

In this tutorial, I use images generated by an [online generator](https://picsum.photos/). You just provide the desired image size, and it creates a random image with those dimensions. This generator can be considered the equivalent of Lorem Ipsum, but for images.

## 🎯 Goal

By the end of this lesson, you will be able to:

- Understand the syntax of the `<img>` tag and how to use it to add images to your HTML page  
- Use the `src` and `alt` attributes to improve image accessibility  
- Add multiple images to your page and modify their visual properties  

## ✅ Conclusion

In this lesson, you learned how to use the `<img>` tag to insert images in an HTML page and how to use the main attributes to optimize image display. Images are powerful tools to enhance the appearance and usability of a website. With this knowledge, you can now enrich your HTML pages with meaningful visual content.
