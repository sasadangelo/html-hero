# 📘 Lesson 3 – Paragraphs

In this lesson, you’ll learn how to add **text paragraphs** to your HTML pages.

## 🎓 What Will You Learn?

- How to use the `<p>` tag to create paragraphs
- Where to place paragraphs within the HTML structure
- What “Lorem Ipsum” text is used for
- Best practices for readability

## 🖼️ Overview

The `<p>` tag is one of HTML’s fundamental elements. It is used to define a **block of text**, or paragraph, which is visually separated from other elements on the page.

In this lesson, you’ll use a Latin text called **Lorem Ipsum**, which is commonly used as placeholder content in web design and development. This text has no specific meaning, but it visually simulates real content so you can focus on layout and structure without distractions. You can use a [Lorem Ipsum generator](https://loremipsum.io/generator/) to create text for your website, which you’ll later replace with your real content.

✍️ Fun fact: “Lorem Ipsum” comes from a work by Cicero written in 45 BC and has been an industry standard in graphic design since the 1960s.

## 🎯 Goal

Add your first paragraph and understand how HTML handles text in documents.
