# 📘 Lesson 6 – Organize Content into Sections with Sub-headings

In this lesson we complete the page by adding all remaining paragraphs, organized into four distinct sections using `<h2>`, `<h3>`, and `<h4>` headings.

## 🎓 What Will You Learn?

- How to use `<h3>` and `<h4>` headings to create a deeper content hierarchy
- How to group related paragraphs under a common subheading
- How to read and maintain an HTML page with many nested levels

## 🖼️ Overview

After lesson 5 the page has several paragraphs but no clear internal structure. Now we split the content into four sections, each with its own heading. This makes the page easier to read and mirrors how real websites organize long-form content.

The full heading hierarchy we use:
```
<h1>  Page title
  <h2>  Section 1
    <h3>  Subsection 1.1
      <h4>  Sub-subsection 1.1.1
  <h2>  Section 2
  ...
```

## 🎯 Goal

Organize all page paragraphs into four clearly labelled sections using multiple heading levels.

## ✅ Conclusion

The page now has a well-structured layout with four sections and proper heading hierarchy — readable for users and meaningful for search engines.
