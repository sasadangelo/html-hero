Risorse

In questa pagina trovi una raccolta di risorse utili per chi vuole imparare a programmare e approfondire lo sviluppo web. Queste sono le risorse che uso io stesso ogni giorno.

Libri Consigliati

I libri rimangono uno degli strumenti di apprendimento più efficaci. Ecco alcuni titoli che consiglio a chiunque voglia migliorare le proprie competenze di sviluppo web:

  • HTML and CSS: Design and Build Websites – Jon Duckett
  • JavaScript: The Good Parts – Douglas Crockford
  • Clean Code – Robert C. Martin
  • The Pragmatic Programmer – Andrew Hunt e David Thomas

Siti Web Utili

Internet è pieno di ottime risorse gratuite. Ecco quelle che reputo più utili per chi inizia con HTML e CSS:

  • MDN Web Docs – La documentazione ufficiale di Mozilla su HTML, CSS e JavaScript.
  • W3Schools – Tutorial interattivi per principianti.
  • CSS-Tricks – Articoli avanzati su CSS.
  • La mia pagina GitHub – Tutto il codice sorgente dei miei progetti.

Strumenti di Sviluppo

Per sviluppare siti web hai bisogno di pochissimi strumenti. Ecco cosa uso io:

  • Visual Studio Code – Editor di codice gratuito e potente.
  • Google Chrome DevTools – Strumenti di debug integrati nel browser.
  • Git e GitHub – Per il controllo della versione del codice.
