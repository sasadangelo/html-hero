Resources

On this page you will find a collection of useful resources for anyone who wants to learn programming and web development. These are the resources I use myself every day.

Recommended Books

Books remain one of the most effective learning tools. Here are some titles I recommend to anyone who wants to improve their web development skills:

  • HTML and CSS: Design and Build Websites – Jon Duckett
  • JavaScript: The Good Parts – Douglas Crockford
  • Clean Code – Robert C. Martin
  • The Pragmatic Programmer – Andrew Hunt and David Thomas

Useful Websites

The internet is full of great free resources. Here are the ones I find most useful for those starting with HTML and CSS:

  • MDN Web Docs – The official Mozilla documentation on HTML, CSS and JavaScript.
  • W3Schools – Interactive tutorials for beginners.
  • CSS-Tricks – Advanced CSS articles.
  • My GitHub page – All the source code of my projects.

Development Tools

To develop websites you need very few tools. Here is what I use:

  • Visual Studio Code – Free and powerful code editor.
  • Google Chrome DevTools – Built-in browser debugging tools.
  • Git and GitHub – For version control.
