# Lesson 17 – Building the Home Page

In this lesson we design the **Home Page** of the site. It introduces a structure completely different from the other pages: a hero area with a background image, a section with circular icons, and a feature articles section.

## What You Will Learn

- How to structure a home page with distinct sections: hero, icons, feature articles
- How to use a CSS background image with `background-image` and `background-size: cover`
- How to position an overlaid text box on the image using `position` and Flexbox
- How to use CSS Flexbox to place images and text side by side in feature sections
- How to load a dedicated home page stylesheet (`home.css`) separate from `default.css`

## Home Page Structure

The home page is made up of three main areas:

1. **Hero area** — full-width background image with an overlaid text box
2. **Circle icon area** — three clickable circular icons linking to the main site sections
3. **Feature sections** — image + text pairs presenting the site content

## Files Changed in This Lesson

| File | Operation | Description |
|---|---|---|
| `index.html` | ✏️ Modified | Complete home page structure |
| `home.css` | ✨ New | Dedicated styles for the home page |

## Goal

By the end of this lesson you will have:
- A professional home page with a hero image, icons and feature sections
- Understood how to separate home page styles into a dedicated CSS file
- Learned how to use `background-image` for CSS background images
