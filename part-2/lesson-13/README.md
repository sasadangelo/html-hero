# Lesson 13 – Building a Header and Footer

In this lesson we add a **header** with a logo and a **footer** with a copyright notice to all pages of the site. This is the first step towards a visually consistent layout.

## What You Will Learn

- What the semantic tags `<header>` and `<footer>` are and why to use them
- How to add a logo to the header using the `<img>` tag
- How to insert copyright text in the footer
- How to apply basic CSS styles to the header and footer (background colour, padding, centering)
- How to replicate the same structure across all pages of the site

## Overview

The `<header>` and `<footer>` tags are HTML5 semantic elements: they tell the browser (and search engines) that that area of the page has a specific role. Using them instead of plain `<div>` elements makes the code more readable and accessible.

In this lesson the header contains the site logo, and the footer contains the copyright text. In later lessons we will enrich both with more content.

## Files Changed in This Lesson

| File | Operation | Description |
|---|---|---|
| All `.html` files | ✏️ Modified | Added `<header>` with logo and `<footer>` with copyright |
| `default.css` | ✏️ Modified | Styles for the header and footer |

## Goal

By the end of this lesson you will have:
- A header with the site logo present on all pages
- A footer with copyright text on all pages
- Understood the difference between semantic tags and generic `<div>` elements
