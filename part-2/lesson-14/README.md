# Lesson 14 – Adding Social Media Buttons to the Header

In this lesson you will learn how to add a logo and integrate customised icons into your website using Font Awesome.

## What You Will Learn

- How to add a logo to the website
- How to integrate Font Awesome into your web project
- How to customise icons to match the site design
- How to create interactive icons using CSS

## Overview

In this lesson we use Font Awesome, a vector icon library, to enrich our website with scalable icons. You will learn how to import the necessary code and customise icons with different sizes, colours and interactivity. We use part of the Font Awesome code to simplify integration.

## Files Changed in This Lesson

| File | Operation | Description |
|---|---|---|
| All `.html` files | ✏️ Modified | Added Font Awesome social media icons to the header |
| `assets/fontawesome/` | ✨ New | Font Awesome webfont files |
| `assets/css/fontawesome.css` | ✨ New | Font Awesome core CSS |
| `assets/css/brands.css` | ✨ New | Font Awesome brand icons CSS |
| `default.css` | ✏️ Modified | Styles for the social media icon buttons |

## Goal

By the end of this lesson you will have:
- Social media icon buttons in the header on all pages
- Understood how to integrate an external icon library into a project
- Learned how to create clickable and interactive icons using CSS
