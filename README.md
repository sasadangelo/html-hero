# 🚀 HTML & CSS Hero – Complete Beginner Course

💻 Welcome to the **complete HTML and CSS guide for beginners!** In this practical, step-by-step course, you’ll learn how to build a modern website using HTML and CSS, even if you’re starting from zero.

🔹 The course is divided into 3 core parts:

## 📘 Part 1 – Build Your First Website

Start by creating the basic structure of a website with 5 interconnected HTML pages. You’ll learn how to use paragraphs, headings, lists, links, and other essential elements.

👉 [Go to Part 1](https://github.com/sasadangelo/html-hero/tree/master/part-1)

## 🎨 Part 2 – Style Your Website

In this section, you’ll add style using CSS: you’ll create a layout with a header, footer, navigation menu, and a professional-looking home page.

👉 [Go to Part 2](https://github.com/sasadangelo/html-hero/tree/master/part-2)

## 🧾 Part 3 – Add Essential Content

Complete your website by adding key content: the “About Us” page, contacts, a resources section, and more.

👉 [Go to Part 3](https://github.com/sasadangelo/html-hero/tree/master/part-3)
